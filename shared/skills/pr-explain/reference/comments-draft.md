# コメント案

検証を通った指摘から、作者に伝えるコメントの案を作る。**投稿しない**（投稿はオーナーの OK の後に呼び出し側が行う）。

## 書き方

- 1 コメント = 1 論点。同じ種類の指摘（共通部品の不使用など）はまとめて PR 全体へのコメントにする
- 行コメントにするものは、置く `path` と行の範囲を見出しに書く。行番号は検証（`verify.md`）で引き直した head の値
- 事実（どこで何をしているか）→ なぜ気になるか（規約の該当箇所・オーナー方針）→ 提案、の順に書く。提案は 1 つに絞らず、「段階 1 はこのままで TODO を残す」など作者が選べる逃げ道も添える
- 作者がすでに PR 本文や既出のコメントで「据え置く」と説明しているものは、蒸し返さない。既出のコメントはフェーズ 7 まで読まないので、案はフェーズ 5 で一度作り、フェーズ 7 の後に見直して消す・書き直す（PR 本文はフェーズ 1 で読んでいるので、本文で説明済みのものはフェーズ 5 で外す）
- 断定できないもの（検証で判定不能）は「〜でしょうか」と質問の形にする
- 口調は依頼・相談の丁寧語。重大度の語（高・中・低）や「AI の指摘」という語は本文に出さない
