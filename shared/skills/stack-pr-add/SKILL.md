現在のスタックの最上部に新規ブランチを追加する。GitHub 公式拡張 `gh-stack` の薄いラッパーとして `gh stack add` を実行する。

## 前提条件チェック

詳細は `../stack-pr-init/SKILL.md` の「前提条件チェック（SSOT）」を参照し同じチェックを行う（再宣言しない）。

## 実行プロセス

1. 前提条件チェックを実行する
2. `gh stack view` で現在のスタック構成を表示する
3. `git status --porcelain` で未コミットの変更があるか確認する
   - 変更がある場合: コミットメッセージをユーザーに確認する（変更内容から目的を判定して提案してよい）。全ファイルをステージするか（`-A`）追跡済みファイルのみか（`-u`）をユーザーに確認する
   - 変更がない場合（既にコミット済みの変更を積む場合）: ブランチ名のみを指定する
4. ブランチ名をユーザーに確認する。コミットメッセージから自動生成させたい場合は `-m` のみ渡してブランチ名を省略してよいことを案内する
5. `gh stack add [-A|-u] [-m "<message>"] [<branch-name>]` を実行する
6. 完了報告: 追加されたブランチ名とスタック内の位置、次のアクション（さらにレイヤーを積むなら `/stack-pr-add` を再実行、まとめて PR 化するなら `/stack-pr-submit`）を案内する
