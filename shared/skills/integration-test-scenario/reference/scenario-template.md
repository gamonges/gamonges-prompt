## 列の意味

- **期待（状態ごとの全文・出ないもの）**: 状態（条件の組）ごとに、画面に出る文・要素を全文で書き、同じ分岐で**出ないもの**も書く。条件付きの文・要素を足す変更では、同じ分岐に常に出る既存の文も並べる（足した 1 文の有無だけを期待にすると、既存の文との矛盾が PASS になる）
- **既存の条件**: 観点が「今どおり」「既存と同じ」なら、その既存の挙動が成り立つ条件と成り立たない条件（いつ押せる・押せない、など）を書き下す。変更が既存の 1:1・一意の制約とぶつかる組み合わせを作るなら、その組み合わせも書く（条件を書かずに「今どおり」とすると、既存の制限とぶつかる組み合わせが観点から落ちる）。`—` にしてよいのは、既存の挙動に触れない、今回の変更で新しく決めた観点だけ
- **新しい形のデータの表示先**: 変更が新しい形のデータを生むなら、そのデータを表示する画面ごとに 1 行。観点ID には、その画面を確かめる ① の観点を対にする（API・network の観点は入れない。API の応答だけで確かめると、画面での崩れを見落とす）。画面を開いて確かめる観点が無ければ、確定する前に ① に観点を足すか、足さない理由をこの列に書く（空のまま確定しない。空の行は印になるだけで、抜けが塞がらない）。新しい形のデータを生まない変更では節ごと省く
