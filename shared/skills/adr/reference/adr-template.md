# ADR のテンプレート

`tmp/adr.md` の雛形と、節ごとの書き方。規則の本体（代替案・懸念・数字の歯止め、文体、表と図）は `adr-authoring-guide.md` にあり、ここでは節ごとに「何を書くか」と「どの原則に従うか」だけを書く。

## 雛形

- Notion に貼るのは、frontmatter の閉じの `---` より後ろだけ（frontmatter の `notion_*` は版の記録で、ADR の本文ではないため）
- `<!-- -->` のコメントは書き方の指示なので、書き出すときに消す
- frontmatter の `#` のコメントは残す（版の記録の意味と式を、ファイルを開いた人が読めるようにするため。Notion に貼る範囲の外）。上書き・追記のときは雛形のコメントで書き直し、`notion_*` の値だけを引き継ぐ
- `（…）` は書き換える欄
- 出典（`D-n`・`tmp/` のファイル）は本文に書かず、`tmp/adr-sources.md` に書く（Notion の読者が開けないため）

```markdown
---
type: ADR
title: （ADR のタイトル。本文の 1 行目と同じ）
description: （決定の内容を 1 文で）
status: draft
# 以下の 3 キーは Notion への反映の版の記録。値を書くのは skill（/adr 反映した <URL> のとき。SKILL.md の「Notion への反映を記録する」）。ADR を書き直すときは既存の値を引き継ぐ。
# notion_page: 起票したら Notion のページの URL。起票前は「未起票」
# notion_synced_at: 反映を記録した時刻「YYYY-MM-DD HH:MM」。記録前は「未反映」（反映済みかの判定は、値が日時か）
# notion_synced_from: 反映を記録した時点の本文のハッシュ（本文は frontmatter の閉じの --- より後ろ。Notion に貼る範囲と同じ）
#   計算: awk '{sub(/[ \t\r]+$/,"")} NR==1&&$0!="---"{exit} f{b=b $0 "\n"; if($0!=""){printf "%s",b; b=""}} /^---$/{c++; if(c==2) f=1}' tmp/adr.md | shasum -a 256 | cut -c1-12
#   行末の空白・改行コード・末尾の空行の違いは数えない。結果が e3b0c44298fc（空の入力）なら本文を数えられていない
#   frontmatter を含めないのは、この値を書いた瞬間にハッシュが変わり、常に不一致になるため
notion_page: 未起票
notion_synced_at: 未反映
notion_synced_from: ''
---
```

## 節ごとの書き方

1. **タイトルと日付**: タイトルは `【ADR】（動詞を含めた決定の内容）【YYYY-MM】`。日付は `YYYY-MM-DD`。採用状況は元資料・会話にある状態を写す。不明なら提案済み。
2. **要約**: 決定・範囲・影響を 3〜4 点で書き、忙しい人が 1 分で本質をつかめるようにする。本文の範囲を超える言い切りをしない（ガイドの「要約について」）。
3. **文脈**: 主観的な形容詞ではなく、事実と数字で書く。数字は元資料・実測にあるものだけを書き、出典を出典表に残す（ガイドの原則 3）。判断の基準（何を優先し、何を受け入れるか）も書く。
4. **決定事項**: 何を決めたかを具体的に書く。図は構造（層・分岐）を示すときだけに使い、項目を並べるときは Markdown の表にする（ガイドの「表と図」）。
5. **検討した代替案と却下理由**: この節は省かない。決定の説得力は退けた案とその理由で決まるため。代替案は元資料に退けた案として記録されたものから取り、論点ごとに 2〜3 個に足りなければ書き足さずにユーザーに聞く。却下理由は元資料の理由を言い回しごと写す（ガイドの原則 1）。
6. **結果とトレードオフ**: 引き受ける負担を、元資料にある制約から漏れなく書く。程度を強める語は使わない（ガイドの「文体の規則」）。役割別の影響の表は、決定の本文と一致させる（ガイドの原則 4）。
7. **懸念と緩和策**: この節は省かない。読む人の不安に答えないと合意が遅れるため。懸念は元資料にある制約から作り、緩和策の無い懸念は「受け入れるリスク」と書く（ガイドの原則 2）。
8. **スコープ外**: 今回やらないことを書き、範囲が膨らむのを防ぐ（ガイドの原則 4）。
9. **参考**: 関連する ADR・PR・公開資料の URL を書く。`tmp/` のファイルや `D-n` などの ID は書かない（Notion の読者が開けないため）。
